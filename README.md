# Business-Sales-Analysis-Dashboard
An interactive sales performance dashboard built in Excel using transactional retail data.
This project analyzes online retail transactions to identify sales trends, customer behavior, product performance, and geographic revenue distribution.

**Tools Used**
Microsoft Excel
Pivot Tables
Pivot Charts
Slicers
KPI Cards

**Key Metrics**
Total Revenue: $9.7M
Total Orders: 532K+
Countries Served: 38
Valid Orders: 92%

**Business Insights**
Revenue peaked during Q4.
The UK generated the highest revenue.
Registered customers accounted for most sales.
Order cancellation rate remained below 10%.
